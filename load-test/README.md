# Навантажувальне тестування (Apache JMeter)

Тест-план `bdt-load-test.jmx` перевіряє, як модуль «Розклад і облік занять» поводиться,
коли з ним одночасно працює багато користувачів. Вимога з документа «Бачення»: перевірка
розкладу на конфлікти та підбір приміщень виконуються не довше 1 с при кількості записів
розкладу до 500.

## Що робить тест-план

Підготовка (один раз перед тестом): у пам’яті JMeter створюється база даних H2 зі скриптів
`schema.sql` і `data.sql`, розклад доповнюється до 500 записів.

Сценарій одного користувача:

| № | Операція | Чим виконується |
|---|---|---|
| 01 | Запуск програми: завантаження розкладу (один раз) | класи програми `ScheduleController`, `ScheduleRepository` |
| 02 | Додавання заняття: перевірка керівника і підбір приміщень | класи програми `ScheduleController`, `SectionCatalog`, `RoomCatalog` |
| 03 | Перегляд розкладу (500 записів) | SQL-запит |
| 04 | Журнал: проведені заняття секції | SQL-запит з параметром |
| 05 | Запит: наповненість секцій | SQL-запит з групуванням |
| 06 | Запит: боржники за місяць | SQL-запит з параметром |
| 07 | Облік заняття: збереження | INSERT |

Між операціями користувач робить паузу 100–200 мс. Для операції 02 встановлено перевірку
тривалості: не довше 1000 мс.

Параметри (задаються ключами `-J` у командному рядку):

| Параметр | Значення за замовчуванням | Зміст |
|---|---|---|
| `projectDir` | `..` | папка проекту |
| `threads` | 10 | кількість одночасних користувачів |
| `rampup` | 5 | час наростання навантаження, с |
| `loops` | 30 | скільки разів кожен користувач повторює сценарій |
| `think` | 100 | пауза між операціями, мс |
| `entries` | 480 | скільки записів розкладу додати до 20 тестових |

## Запуск

1. Встановити Java 17 або новішу та розпакувати Apache JMeter 5.6.3.
2. Зібрати програму: `./build.sh` (з’явиться `bdt.jar`).
3. Запустити скрипт, указавши папку JMeter:

```
bash load-test/run-load-test.command /шлях/до/apache-jmeter-5.6.3
```

Скрипт копіює `bdt.jar` і `lib/h2-2.2.224.jar` у папку `lib` JMeter і чотири рази запускає
тест-план: для 1, 10, 25 і 50 користувачів. Результати кожного запуску лежать у
`load-test/results/threads-N`: `results.jtl` (усі заміри), `jmeter.log`, `report/index.html`
(звіт із графіками).

Щоб відкрити тест-план у графічному інтерфейсі JMeter, спочатку скопіюйте в папку `lib` JMeter
файли `bdt.jar` і `lib/h2-2.2.224.jar`, а у змінній `PROJECT_DIR` елемента «Параметри тесту»
вкажіть повний шлях до папки проекту.
